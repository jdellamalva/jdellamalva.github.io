- This repository and every pushed branch are public.
- Keep content limited to intentionally public software-project summaries.
- Do not add personal résumé data, interview notes, employment-search plans,
  internal business figures, credentials, or private repository source URLs.

- Validate with npm run lint, npm run typecheck, npm run build, and
  npm run verify:portfolio before publishing.
